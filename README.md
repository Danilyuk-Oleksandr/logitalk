# 💬 Logi Talk Pro

**Logi Talk Pro** — це простий клієнт-серверний месенджер, створений на Python. Він дозволяє користувачам спілкуватися в реальному часі, надсилати текстові повідомлення та обмінюватися зображеннями через локальну мережу.

## 🚀 Можливості

* 💬 **Обмін повідомленнями** — надсилання та отримання текстових повідомлень у реальному часі.
* 🖼️ **Надсилання зображень** — можливість ділитися зображеннями безпосередньо в чаті.
* 👤 **Персональний нікнейм** — можливість встановити власне ім'я користувача.
* 🎨 **Графічний інтерфейс** — зручний інтерфейс, створений за допомогою CustomTkinter.
* 🟢 **Багатокористувацький режим** — можливість одночасного підключення кількох користувачів.
* 🔄 **Обмін повідомленнями в реальному часі** — використання потоків (Threading) для одночасної обробки клієнтів.
* 👥 **Аватари** — круглі аватари користувачів і системи.
* 📱 **Анімоване меню** — бічна панель із можливістю зміни нікнейму.

## 🛠️ Технології

* **Python** — основна мова програмування.
* **Socket** — мережеве з'єднання між клієнтом і сервером.
* **Threading** — паралельна обробка підключень і отримання повідомлень.
* **CustomTkinter** — створення графічного інтерфейсу.
* **Pillow (PIL)** — обробка зображень та створення аватарів.
* **Base64** — кодування зображень для передавання через мережу.

## 📦 Встановлення

**1. Клонуйте репозиторій**

```bash
git clone https://github.com/USERNAME/Logi-Talk-Pro.git
cd Logi-Talk-Pro
```

**2. Встановіть необхідні бібліотеки**

```bash
pip install customtkinter pillow
```

## ▶️ Запуск

Для роботи месенджера необхідно запустити сервер, а потім клієнт.

**1. Запустіть сервер**

```bash
python server.py
```

Сервер працює на порту `8080` і очікує на підключення користувачів.

**2. Запустіть клієнт**

В іншому терміналі виконайте:

```bash
python client.py
```

Щоб підключити декількох користувачів на одному комп'ютері, можна запустити кілька екземплярів клієнта.

## 🖥️ Як користуватися

1. Запустіть сервер.
2. Відкрийте клієнтську програму.
3. Розгорніть бічне меню та введіть свій нікнейм.
4. Натисніть кнопку **«Зберегти»**.
5. Введіть повідомлення в поле чату та натисніть кнопку відправлення.
6. Щоб надіслати зображення, натисніть кнопку 📂 та виберіть потрібний файл.

## 🌐 Принцип роботи

Logi Talk Pro використовує архітектуру **Client-Server**.

* **Сервер** приймає підключення клієнтів, отримує повідомлення та пересилає їх іншим підключеним користувачам.
* **Клієнт** забезпечує графічний інтерфейс, надсилає повідомлення та відображає отримані дані.
* **Потоки** дозволяють серверу одночасно обробляти декілька клієнтів.
* **TCP** забезпечує передавання даних між клієнтом і сервером.

Для обміну даними використовуються текстові повідомлення з типом `TEXT` та зображення з типом `IMAGE`.

## ⚙️ Налаштування

За замовчуванням сервер використовує такі параметри:

```python
HOST = '0.0.0.0'
PORT = 8080
```

`HOST = '0.0.0.0'` дозволяє серверу приймати підключення через доступні мережеві інтерфейси, а `PORT = 8080` визначає порт сервера.

У клієнті за замовчуванням використовується адреса `localhost`, тому для підключення через інші пристрої в локальній мережі потрібно змінити адресу сервера.
